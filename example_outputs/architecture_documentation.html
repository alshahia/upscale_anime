Anime Super-Resolution

Complete Architecture Documentation & Training Pipeline Guide

Overview

This project implements a Progressive Ensemble Distillation system for anime super-resolution. It combines state-of-the-art architectures with advanced knowledge distillation techniques to achieve high-quality upscaling with efficient inference.

Complete training pipeline from data ingestion to final ensemble model

Model Architectures

Model A: SPAN-Tiny with MTKD + FAKD

NTIRE-winning architecture optimized for super-resolution with parameter-free attention.

  • Architecture: SPAN (Swift Parameter-free Attention Network)
  • Parameters: ~250K (Tiny variant with 26 channels)
  • Key Features: Parameter-free attention, ConvLoRA adaptation
  • Training: 2-stage (Knowledge Aggregation → Student Distillation)
  • Losses: L1 + MTKD (Wavelet) + FAKD (Feature Affinity)
  • Inference Speed: 0.001-0.005s per 720p frame

Model B: Mamba-PAN with Directional Scanning

State Space Model with linear complexity and 4-direction scanning mechanism.

  • Architecture: Mamba-PAN with hierarchical blocks
  • Parameters: Variable based on configuration
  • Key Features: 4-direction scanning (H, V, RH, RV), O(N) complexity
  • Training: Direct student training with teacher guidance
  • Losses: L1 + MTKD + Directional FAKD + Cross-Direction Consistency
  • Advantage: Better long-range dependencies vs O(N²) attention

Ensemble: Meta-Teacher Distillation

Combines Model A and Model B as frozen teachers for ultra-lightweight student.

  • Input: Frozen Model A + Model B checkpoints
  • Output: Tiny Student (~100K parameters)
  • Method: Ensemble predictions as soft targets
  • Use Case: Maximum efficiency deployment

Training Pipeline

Stage 1: Knowledge Aggregation

Train a network to fuse outputs from multiple teacher models (EDSR, RCAN, SwinIR).

# Teachers: EDSR, RCAN, SwinIR (pretrained on DIV2K) # Aggregation: DCTSwin blocks with frequency-domain attention # Loss: L1 between aggregated output and ground truth HR output = AggregationNetwork([edsr(lr), rcan(lr), swinir(lr)]) loss = L1Loss(output, hr)

Stage 2: Student Distillation (Model A)

Train SPAN-Tiny student with multi-teacher knowledge distillation.

# MTKD: Multi-Teacher Knowledge Distillation (Wavelet-based) # FAKD: Feature Affinity Knowledge Distillation loss_l1 = L1Loss(student_output, hr) loss_mtkd = WaveletDistillation(student_output, teacher_output, hr) loss_fakd = FeatureAffinity(student_features, teacher_features) total_loss = loss_l1 + λ_mtkd * loss_mtkd + λ_fakd * loss_fakd

Stage 2: Student Training (Model B)

Train Mamba-PAN with direction-aware distillation.

# Directional scanning: Horizontal, Vertical, Reverse-H, Reverse-V # Cross-direction consistency ensures stable predictions student_pred = MambaPAN(lr, direction=['h', 'v', 'rh', 'rv']) loss = L1 + MTKD + FAKD + Consistency(direction_outputs)

Stage 3: Ensemble Training

Create ensemble from frozen models and distill to tiny student.

# Load frozen checkpoints model_a = load_checkpoint('model_a_best.pth') model_b = load_checkpoint('model_b_best.pth') # Ensemble as meta-teacher ensemble_pred = (model_a(lr) + model_b(lr)) / 2 # Train tiny student with ensemble guidance student_loss = DistillationLoss(student_pred, ensemble_pred, hr)

Data Pipeline

Degradation Model (RealESRGAN-style)

Training uses realistic degradation to simulate real-world low-quality inputs:

  • Blur: Gaussian with varying kernel sizes (7-21) and sigma (0.1-3.0)
  • Noise: Gaussian noise with sigma 0-50
  • Resize: Random down/up-sampling (0.15x to 1.5x)
  • JPEG: Compression artifacts (quality 60-100)

Video Processing

Supports training from video sources with automatic frame extraction:

  • Pre-extraction: Extract all frames before training (faster)
  • On-demand: Extract frames during training (less storage)
  • Quality filtering: Automatic blur and duplicate detection
  • Formats: MP4, AVI, MKV, MOV, WebM
